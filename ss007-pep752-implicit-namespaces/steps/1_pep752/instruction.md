Ship the feature as `packagenamespaces` rooted at `Lib/packagenamespaces/` with submodules `packagenamespaces.normalize`, `packagenamespaces.matching`, `packagenamespaces.grants`, `packagenamespaces.uploads`, `packagenamespaces.metadata`, `packagenamespaces.policy` and `packagenamespaces.cli` runnable as `python -m packagenamespaces`. The design states that the package root re-exports every public symbol and that GrantStore, RepositoryIndex and SecurityPolicy import from the package root.

Provide `normalize_name`, `is_valid_namespace` and `hyphen_depth` for name handling where `Foo.bar_BAZ becomes foo-bar-baz` demonstrates case folding and separator collapsing to a single hyphen with names holding newlines, tabs or other control characters are invalid as part of validity that requires ASCII letters or digits at both ends and rejects empty values plus leading or trailing separators plus spaces and punctuation. Expose `namespace_matches` for prefix checks where a candidate equals the namespace or starts with the namespace followed by a hyphen so foo matches foo-bar, not foobar holds with both inputs normalized before comparison.
